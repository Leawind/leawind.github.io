# 功能总览

SSR 的核心功能是“可交互的越肩第三人称”，并在此基础上提供多组可组合的体验选项。

| 功能                 | 玩家侧表现                                                         | 实现要点                                                        |
| -------------------- | ------------------------------------------------------------------ | --------------------------------------------------------------- |
| 越肩视角             | 相机默认偏左 `0.75` 格、后移 `4` 格，可切肩和上下前后微调          | 以独立 `ShoulderSurfingCamera` 计算局部偏移、旋转和过渡         |
| 相机解耦             | 镜头可独立旋转，角色不会立刻随鼠标转身                             | 拦截 `LocalPlayer.turn`，把鼠标增量交给独立相机；再改写移动向量 |
| 自由观察             | 默认按住左 Alt 后可保持行进方向，同时自由看向别处                  | 只累计相机旋转偏移，不推进玩家转向，也不旋转输入                |
| 交互瞄准             | 第三人称下仍按相机所见选中方块、实体、物品使用目标                 | 为方块、实体和近战范围重建射线检测上下文                        |
| 静态/自适应/动态准星 | 准星可保持中央、瞄准时移动，或始终投影到实际命中点                 | 射线命中点经模型视图/投影矩阵换算为 HUD 位移                    |
| 遮挡反馈             | 相机与实际交互点不一致时显示指示符；瞄准时可显示遮挡准星           | 额外进行一条“遮挡”射线，并按屏幕距离判断                        |
| 玩家可见性           | 视点贴近模型时模型淡出；可在瞄准/攀爬时调整                        | 在相机实体渲染阶段给颜色 alpha 限幅，并换用透明盔甲渲染类型     |
| 动态镜头             | 冲刺、骑乘、鞘翅、攀爬、瞄准时可分别修正偏移；支持拖拽、摆动与转场 | 通过内置事件处理器叠加偏移乘数/加数，按速度计算旋转/平移效果    |
| 视听修正             | 可覆盖 FOV、开关视角晃动，让玩家自身声音以相机为中心               | 注入 `Camera.calculateFov`、`GameRenderer` 和实体绑定音效       |

## 视角切换与快捷键

模组定义了一个 `SHOULDER_SURFING` 视角枚举值，但底层仍借用原版的 `THIRD_PERSON_BACK` 相机类型。它会接管原版“切换视角”按键，在第一人称、越肩、后方第三人称和前方第三人称之间按配置循环；也可选将原版后方第三人称直接替换成越肩模式。

默认快捷键为方向键调整水平和远近、Page Up/Page Down 调整高度、`U` 切肩、左 Alt 自由观察。另有直接进入各视角、切换相机耦合和 X/Y/Z 偏移预设的未绑定快捷键，均能在控制设置中配置。

## 配置的边界

配置是本地客户端配置（README 指向 `.minecraft/config/shouldersurfing-client.cfg`），不需要服务端安装。主要配置组为：

- `perspective`：默认视角、是否记住上次选择、是否替换原版第三人称；
- `camera`：偏移及限幅、预设、状态相关修正、过渡、FOV、晃动、拖拽与摆动；
- `crosshair` 与 `object_picker`：准星类型、可见条件、遮挡提示、射线距离、射线起点和方向；
- `player`：透明条件、交互时转身策略和速度；
- `audio`：是否将玩家发出的声音置于相机中心；
- `integrations`：例如 Curios 槽位物品触发自适应准星。
