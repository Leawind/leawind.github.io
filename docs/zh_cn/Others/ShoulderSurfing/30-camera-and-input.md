# 相机与输入

## 相机不是原版第三人称相机的固定偏移

`ShoulderSurfingCamera` 保存自己的偏移、上一帧偏移、目标偏移、旋转、自由观察旋转增量和镜头距离。每个逻辑 tick 它向目标偏移插值；每个渲染帧则按 partial tick 插值得到最终姿态。因此切肩、按键调整和状态变化都可以平滑过渡。

公共 `CameraMixin` 在原版 `Camera.alignWithEntity` 中做两件关键事：

1. 在原版将相机移动到普通第三人称位置时，取消那次移动，改为调用 `ShoulderSurfingCamera.setup` 并按 `renderOffset` 移动。局部偏移会换算为相机的前、上、左向量。
2. 在玩家位置确定后，将原版相机的 yaw/pitch 改为独立相机的渲染旋转；额外叠加基于速度的摆动（pitch/roll）。Fabric/NeoForge 的专用 Mixin 还把 roll 写进四元数。

这使“相机看向哪里”不必等于“角色身体朝向哪里”。

## 穿墙与环境适配

相机不会直接穿过方块。`maxZoom` 从实体眼部附近的八个采样点向目标相机位置做 `ClipContext.Block.VISUAL` 射线；一旦碰撞便以最近命中距离缩短镜头。长度缩短也受上一帧最大距离约束，以避免镜头在墙边突然弹跳。

目标偏移还会经过一串内置处理器：

- 按实体缩放和 `CAMERA_DISTANCE` 属性调整距离；骑乘生物时也可读取坐骑属性；
- 对骑乘、冲刺、瞄准、鞘翅飞行和攀爬分别加上配置的乘数与偏移；
- 低头达到阈值时把 X/Y 偏移居中；
- “动态偏移”会测试侧向偏移的空间，侧面受墙阻挡时自动把 X/Y 偏移缩回；
- 最后应用每个轴的配置限幅。

相机还会根据去除重力后的实体速度做反向拖拽；垂直与横向速度可使镜头产生 pitch/roll 摆动。骑乘时会补偿坐骑转向，矿车则单独修正其乘客旋转偏移。

## 鼠标、角色朝向与移动

`LocalPlayerMixin` 覆写 `turn`：鼠标的 yaw/pitch 增量优先交给 `ShoulderSurfingCamera.turn`，只有未启用越肩时才调用原版逻辑。`MouseHandlerMixin` 同时让原版把越肩当作第一人称，从而不会因第三人称分支跳过玩家转向相关处理。

解耦时的处理如下：

```text
鼠标增量 → 独立相机旋转
键盘移动向量 → 以相机/玩家 yaw 差旋转 → 原版移动系统
```

若角色正在移动，`InputHandler.updateMovementInput` 会使角色朝移动方向渐进转身，并将输入向量旋回到角色坐标系；所以按“前进”仍代表朝画面前方走。静止时可按配置让角色的 pitch/yaw 部分跟随相机。按住自由观察键时，该函数直接返回：镜头可转动，但原有移动与角色方向保持不变。

当使用物品、攻击、交互或选取需要面对目标时，模组会把玩家转向相机准星射线命中的位置，并以 `turning_lock_time` 保持数 tick。瞄准也可强制相机重新耦合。离开越肩模式前同样会让角色朝向当前准星目标，减少切回第一人称时的方向突变。

## 例外与第一人称回退

鞘翅飞行强制相机耦合，睡眠时保持解耦；旁观其他实体也有单独旋转处理。若配置使用 `STATIC_WITH_1PP` 或 `DYNAMIC_WITH_1PP` 准星，瞄准期间会临时切回第一人称，停止瞄准后自动回到越肩。望远镜使用时则按第一人称处理覆盖层并跳过自身模型渲染。
